# Playnite

### Open-source game library manager for everything

Playnite is a free, open-source game library manager that aggregates Steam, Epic, GOG, Xbox, Battle.net, and emulators into one beautiful interface. Your entire gaming library, organized and launchable from one place.

<br>

---

## Features

| | |
|:---|:---|
| **All Platforms** | Import games from Steam, Epic, GOG, Xbox, Itch.io, and more |
| **Emulator Support** | Seamlessly integrate emulated games alongside PC library titles |
| **Themes & Plugins** | Hundreds of community themes and plugins to customize everything |
| **Fullscreen Mode** | A beautiful couch-gaming mode for TV setups with controller navigation |
